# Media Credits

The TechAxis Global (TAG) website uses a combination of custom code-native animations and licensed media assets. This document tracks the provenance and licensing of all external media files used in the project.

*Note: As this is a fresh build utilizing progressive-enhancement fallbacks, the initial deployment relies primarily on the code-native fallbacks (`GradientMesh`, `DataNetwork`, `DotGrid`) while placeholder slots are wired up in `src/data/media.ts`.*

## Current Assets

| Slot Key | Asset Type | File Path | Source / Creator | License |
| :--- | :--- | :--- | :--- | :--- |
| *All Slots* | Code-Native | `src/components/GradientMesh.tsx` etc. | Generated (Internal) | Proprietary / Internal |
| `home-film` | Video | `/public/media/video/brand-film.mp4` | Client Provided | Proprietary (Client) |

*(When commercial stock footage is downloaded and added to `/public/media`, record the Pexels/Unsplash/Mixkit URL and Creator Name here).*
